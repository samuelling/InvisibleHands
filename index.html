The ideaThree panels, no jargon

1

Your app has knobs

It makes a short list of things it wouldn’t mind someone else turning. Speed. Colour. Wobble. The big button that makes it go sploosh.

2

Someone, somewhere, turns them

Another app joins the same room (a code like moss-kiln-opal-fern-42) and its hands reach in. It might be a synth, a phone, a script, a friend. Your app does what it’s told, within the rules you set.

3

And it talks back

Apps can publish their own wiggles too (a beat, a loudness, a sway) as outputs. Anyone in the room can plug those into somebody else’s knob. Then it gets weird.

It’s a patch cable. On a modular synth any output can go into any input. Here the modules are apps and the cable is the entire internet.
It’s a remote you lend out. You choose which buttons are on it. You can take it back with one tick box. Your own hands always win.
It’s a séance for software. Things in your app move by themselves, pushed by someone you can’t see. That’s the name.
Room where apps meet
A made-up code. Everyone who has it is in the same room. Up to 16 apps.
Control a knob
Something an app lets others move. Always a number from 0 to 1.
Output a wiggle
Something an app sends out for others to use, also 0 to 1.
Set put it there
“Put Speed at 0.7.”
Swing an LFO; “mod”
“Wobble Speed up and down around wherever its owner left it.”
Envelope a shape; “ramp”
“Jump up, then fall back slowly.” Sent once and played at the far end, so the internet can’t smudge it.

Road bumps

The pink one arrives in a stutter: each little set hits a different pothole. The blue one goes as a single message (“up in 80 ms, down in 600 ms”) and is played by the far app on its own clock. It comes out late, but it comes out perfect. That’s why Invisible Hands has ramps.

A web page, by hand

One file, eight lines

<script src="https://samuelling.github.io/InvisibleHands/invisible-hands.js"></script>
<script>
const hands = InvisibleHands.create({
  app: 'my-app', name: 'My App',
  params: [{ id: 'speed', label: 'Speed',
    get: () => speed, set: v => { speed = v; } }]
});
settings.append(hands.panel());
</script>

Before you shipGet a key

The relay is free to use and two people pay for it. A key keeps one runaway loop from using up everybody’s month.

How it works

  1. Build without oneRun the little relay on your own computer (one command, in the kit). No key, no limits, no internet needed.
  2. Ask onceTell us your app’s name, its web address and what it’ll move. Through the finger guns or the BBS, whichever you like.
  3. Get your keyA string like ih_k2v9…, tied to your app’s web address. Copied onto another site, it does nothing.
  4. Paste it increate({ key: 'ih_…' }). Done.

Ask for one

Either way, a person reads it and writes back, usually within a few days.

With finger guns → On the BBS →

On the BBS, post in megaZINE Submissions with “Invisible Hands key” as the title. For a program that isn’t a web page (Python, a command line), ask for a native key and keep it to yourself.

Each key gets 2 million frames a month (a frame is one bundle of moves). That’s about 45 minutes a day of a patch swinging knobs 25 times a second. Slow swings cost far less. Need more? Ask.

MannersHouse rules & small print

An app that can be moved

  1. Shows when it’s linked.
  2. Has a switch that stops remote control. Local hands win.
  3. Clamps every number it gets, and ignores controls it doesn’t have.
  4. Shows other apps’ names as plain text, never as code.
  5. Never offers anything that deletes, buys, records, or flashes like a strobe.

The small print

  • Only numbers and short labels travel. No pictures, no sound, no personal data.
  • The relay keeps a guest list per room and a monthly count. It stores no values and keeps no logs of what moved.
  • A room code is the only way in. Share it like a house key.
  • 16 apps a room. Sends are capped so nobody can drown a room.
  • The whole thing is open: the protocol is one page, and you can run your own relay.
