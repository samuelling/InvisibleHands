The hands

An LFO swings a control around wherever its owner left it. An envelope rises to the top and falls back, and is played on the far machine so the network cannot roughen it.

Patch matrix

Outputs down the side, knobs across the top. Click a pin to run a cable: that output swings that knob, around wherever its owner left it. Click a lit pin to set its depth, flip it, or pull it out. The patch is saved in this page’s address, so a copied link brings the cables with it.
